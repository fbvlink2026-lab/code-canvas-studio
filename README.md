# GUI Editor Pro

A complete visual code editor supporting HTML, CSS, JS, PHP, XML, and JSON with two-way sync between Visual Canvas and Source Code.

## Features
- **Visual Drag & Drop**: Arrange elements like Android Studio/Figma.
- **Two-Way Sync**: Click element -> Highlight Code. Edit Code -> Update Visuals.
- **Multi-Language Support**: Dedicated parsers for different file types.
- **Property Inspector**: Real-time adjustment of styles, attributes, and data bindings.

## Tech Stack
- React + TypeScript
- Vite
- Zustand (State Management)
- Monaco Editor (Code Editing)
- Tailwind CSS (UI Styling)
- dnd-kit (Drag and Drop)

## Installation
1. Clone the repo.
2. Run `npm install`.
3. Run `npm run dev`.
